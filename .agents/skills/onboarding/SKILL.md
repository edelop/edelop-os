Read `procedury/onboarding/README.md` from the repository root and follow its router.
Read `.onboarding/postep.md` and `.onboarding/profil.md`, then only the current stage.
The shared procedures are authoritative; do not duplicate their lesson content here.

The assistant shall follow `AGENTS.md` for shared rules and obtain consent before
replacing existing content. Exercises remain the learner's responsibility.
If the user asks for unrelated work, then the assistant shall handle that request
without starting a lesson because an onboarding stage is incomplete.
